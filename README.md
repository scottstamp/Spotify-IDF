# CYD Spotify Desk Controller (ESP-IDF v6.0.2)

A native **ESP-IDF v6.0.2** firmware port for the **Cheap Yellow Display 2-USB (CYD / ESP32-2432S028R)**, transforming it into a fast, responsive, and modern Spotify desk controller.

Powered by **LVGL 9**, hardware DMA display acceleration, and a dual-core FreeRTOS architecture, this port eliminates the UI stutters, flash wear, and memory fragmentation commonly found in legacy Arduino implementations.

## Features

- **Modern LVGL 9 UI**:
  - True pitch-black background (`#000000`) optimized for CYD LCD viewing angles.
  - Large centered 170×170 album artwork with 10px rounded corners.
  - Interactive album art acting as a touch Play/Pause button with pause overlay badge.
  - Flat Next / Previous flanking touch buttons with responsive hit testing.
  - Montserrat typography (12pt song & artist, 10pt duration counters).
  - Smooth 50 Hz locally interpolated progress bar.
- **Dual-Core FreeRTOS Architecture**:
  - **Core 0**: Wi-Fi, TLS 1.2, Spotify Web API polling, and OAuth token refreshes.
  - **Core 1**: LVGL 9 render pipeline and XPT2046 hardware touch polling.
  - **Zero UI Freezes**: Display animations and touch response remain perfectly fluid while network operations run in the background.
- **Zero-RAM ROM Streaming JPEG Decode**:
  - Leverages the ESP32's built-in ROM JPEG decoder (`esp32/rom/tjpgd.h`).
  - Streams image data directly from HTTP chunks into a 150×150 RGB565 framebuffer using only a **3.5 KB** scratchpad buffer.
  - Eliminates heap fragmentation and removes all SPIFFS/LittleFS flash-write wear.
- **Adaptive Polling with Crossfade & Automix Support**:
  - **1000ms** base playback polling cadence.
  - Enters rapid **600ms** polling throughout crossfade, Automix, and song transitions (`remaining <= 35s` or `progress <= 8s`).
  - Estimates real-time playback progress between network queries via local timer interpolation.
  - Immediate metadata dispatch: Track title and artist update on screen instantly before image streaming starts.
- **Market Relinking (`market=from_token`)**:
  - Queries Spotify API with user token market context to align duration with regional releases and strip 2+ KB of unused country code data.
- **Smart Screen Power Management & Burn-In Prevention**:
  - Enters deep sleep when no song is playing for longer than **30 seconds**.
  - **Zero Frame Wear**: Flushes a pure black frame to the display's internal GRAM and executes the ILI9341 `DISPOFF` (0x28) command to completely unbias the liquid crystals and prevent static image retention or panel burn-in.
  - Shuts off the LED backlight completely.
  - Wakes up immediately upon tapping the touch screen or when a song starts playing on Spotify.
  - Restores the UI to GRAM and executes `DISPON` (0x29) before reenabling the backlight for tear-free, seamless wake-up.
  - Initial wake-up tap in the dark is safely consumed without accidentally triggering buttons.
- **Captive Portal Web Provisioning**:
  - Onboard SoftAP (`CYD-Spotify-Setup`) and web server for entering Wi-Fi credentials, Spotify Client ID, and Client Secret into non-volatile storage (`nvs_flash`).

## Hardware Specifications

- **Target Board**: ESP32-2432S028R ("Cheap Yellow Display" 2-USB / CYD)
- **SoC**: ESP32-D0WD-V3 (Dual Core Tensilica Xtensa 32-bit LX6 @ 240 MHz, 520 KB SRAM, 4 MB Flash, No PSRAM)
- **Display**: 2.8" ILI9341 320×240 TFT LCD via `SPI2_HOST` (40 MHz DMA)
- **Touch**: XPT2046 Resistive Touch Controller via `SPI3_HOST`

## Getting Started

### Prerequisites

- [ESP-IDF v6.0.2](https://docs.espressif.com/projects/esp-idf/en/v6.0.2/esp32/get-started/) installed.
- USB-C cable connected to the UART/PROG port of the CYD board.

### Build and Flash

1. Open your ESP-IDF PowerShell environment:
   ```powershell
   . C:\Espressif\tools\Microsoft.v6.0.2.PowerShell_profile.ps1
   ```

2. Navigate to this directory:
   ```powershell
   cd cyd-spotify-idf
   ```

3. Build the project:
   ```powershell
   idf.py build
   ```

4. Flash the firmware to your device (replace `COM3` with your serial port):
   ```powershell
   idf.py -p COM3 flash
   ```

5. Monitor serial logs:
   ```powershell
   idf.py -p COM3 monitor
   ```

## Spotify Developer Setup

1. Go to the [Spotify Developer Dashboard](https://developer.spotify.com/dashboard) and log in.
2. Click **Create app**:
   - **App name**: `CYD Spotify Controller` (or any name)
   - **App description**: `Desk controller`
   - **Redirect URI**: `http://192.168.4.1/callback`
   - Select **Web API** under "Which API/SDKs are you planning to use?".
3. Save the app and open **Settings** to retrieve your **Client ID** and **Client Secret**.

---

## Device Configuration

1. On first boot (or when Wi-Fi is unavailable), the device broadcasts a Wi-Fi network:
   - **SSID**: `CYD-Spotify-Setup`
   - **Password**: None (Open)
2. Connect your phone or PC to `CYD-Spotify-Setup`.
3. Open a browser and navigate to `http://192.168.4.1/`.
4. Enter your home Wi-Fi SSID, Wi-Fi Password, Spotify Client ID, and Client Secret.
5. Click **Save & Connect**.
6. The screen will display a link to authenticate. Click **Log In with Spotify** to link your account.
7. Once linked, the display immediately switches to the Now Playing player screen.
